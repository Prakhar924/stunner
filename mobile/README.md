# Stunner mobile

Expo React Native app for iOS and Android using the existing Supabase backend.

1. Copy `.env.example` to `.env` and add the Supabase URL and publishable key.
2. Run `npm install`.
3. Run `npm start`, then scan the QR code with Expo Go.

The first build includes email/username authentication, email recovery, discovery swipes, matches, and profile editing. Native photo selection is present; production storage upload, chat UI, push notifications, moderation, and store signing remain follow-up milestones.
